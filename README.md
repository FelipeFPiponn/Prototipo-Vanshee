# Prototipo-Vanshee
Prototipo de interaccion con sistemas operativo mediante comandos de usuario dictados por voz.(integracion de IA)


"Para desarrolladores de software, profesionales multitarea y usuarios de estaciones de trabajo que buscan optimizar sus tiempos y reducir la fricción operativa al interactuar con el computador, el proyecto V.anshee es un asistente virtual de escritorio controlado por voz e impulsado por modelos de lenguaje de inteligencia artificial. A diferencia de los asistentes comerciales rígidos o dependientes de interfaces propietarias, nuestro producto permite una interpretación contextual en lenguaje natural para la automatización local de herramientas de desarrollo (IDEs, consola), control de ventanas/aplicaciones y persistencia configurable de atajos, proporcionando una experiencia fluida, ergonómica y adaptable a flujos de trabajo técnicos."
